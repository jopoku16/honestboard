Honest leaderboards

Agent benchmark leaderboards rank systems by one score and announce a new record whenever it rises. This page shows how much of that survives sampling noise: rank intervals, the set of systems that cannot be ruled out as best, and an audit of every record claim, computed from each leaderboard's own per-task results.

Computed with honestboard from public per-task results (SWE-bench experiments repository; Terminal-Bench 2 leaderboard dataset), fetched 2026-10-12. Tasks are the unit of resampling; most submissions are a single run; tuning against public tasks is not modelled. A record that is not significant is not shown to be worse or equal: the data cannot tell it apart from the previous record. Tuning against public tasks is not modelled. Draft, not peer reviewed.
